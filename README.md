# Lumina Photo

**Lumina Photo** — быстрый, современный просмотрщик фотографий, каталогизатор и неразрушающий редактор изображений для Windows на **C++20** и **Qt 6**.

Проект сочетает мгновенное окно быстрого просмотра при открытии файлов из Проводника Windows и полноценную медиатеку с альбомами, SQLite-индексацией, слоевыми эффектами, инспектором метаданных (включая AI-промпты и слои PSD) и экспортом анимированных GIF.

---

## Основные возможности

### 1. Два режима работы: Quick Viewer и Библиотека
* **Quick Viewer (`QuickViewerWindow`)** — запускается мгновенно при передаче пути к файлу через аргументы командной строки (двойной клик в Проводнике) или в режиме быстрого просмотра:
  * Плавный зум колесом мыши с привязкой к курсору, панорамирование перетаскиванием, режимы «По окну» / `100%`, поворот, удаление в корзину Windows с подтверждением и навигация по соседним файлам папки с нижней кинолентой миниатюр.
  * Переключение цвета фона холста (прозрачность / белый / чёрный) для удобной оценки PNG, SVG, ICO и PSD с альфа-каналом.
  * Плавное воспроизведение анимированных **GIF** и **WebP** (`QMovie`) с управлением паузой/воспроизведением, покадровой прокруткой и таймлайном.
  * Просмотр слоёв **Adobe Photoshop (`.psd`)**: список слоёв, переключение видимости отдельных слоёв и просмотр каждого слоя изолированно.
  * Встроенный быстрый редактор прямо в окне просмотра и кнопка перехода в полную библиотеку (`Открыть в библиотеке`).
* **Полноценная медиатека (`MainWindow`)**:
  * **Асинхронное сканирование папок** (`QtConcurrent`) с быстрым чтением размеров из заголовков файлов (без декодирования пикселей при индексации) и пакетной записью в **SQLite** (режим `WAL`).
  * **Умная организация**: разделы *Все фото*, *Избранное* (звёздочки), *Папки* (с поддержкой вложенных директорий) и пользовательские *Альбомы* с выбором векторной иконки (`AlbumIcons`).
  * **Поиск и фильтрация** по имени файла, пользовательским подписям и модели камеры в реальном времени.
  * **Контроль целостности**: проверка отсутствующих на диске файлов и очистка устаревших записей из базы.

### 2. Неразрушающий слоевой фоторедактор
Все изменения сохраняются в базе данных (`PhotoEdits` в формате JSON) без перезаписи исходного файла, пока пользователь явно не выберет экспорт:
* **Геометрия и кадрирование**: интерактивная рамка кропа с произвольным фокусом, плавный зум внутри области кадрирования (`0–300%`), выравнивание горизонта (`-25° … +25°`), поворот на 90° и базовое повышение резкости.
* **Свет и цвет**: экспозиция / заполняющий свет, света (*Highlights*), тени (*Shadows*), контраст, насыщенность, цветовая температура, оттенок (*Tint*) и полный цветовой круг (`-180° … +180°` *Hue Shift*).
* **Стек эффектов (`EffectLayer`) в стиле Photoshop**:
  * Возможность накладывать несколько слоёв эффектов друг на друга, менять их порядок, регулировать интенсивность, второй параметр и включать/выключать видимость каждого слоя.
  * **40+ встроенных пресетов** в 3 категориях:
    * *Обработка*: резкость, сепия, Ч/Б, тёплый свет, зернистость плёнки, цветовой оттенок, насыщенность, мягкий фокус, сияние, Ч/Б светофильтр, Ч/Б фокус, градиентный тон.
    * *Художественные*: инфракрасная плёнка, ломография, Holga, HDR-эффект, синемаскоп, эффект Ортона, винтаж 60-х, инверсия, тепловизор, кросс-процесс, постеризация, дуплекс (Duo-Tone).
    * *Творческие и рамки*: усиление, смягчение, виньетка, пикселизация, спортивный фокус, карандашный набросок, неон, комикс-растр, контур, отбрасываемая тень, паспарту, Polaroid.
  * **Автокоррекция**: *Мне повезёт!*, *Автоконтраст*, *Автоцвет*, *Автобаланс*.
  * **Свободные текстовые слои (`TextOverlay`)**: добавление нескольких текстовых надписей, перетаскивание мышью прямо по холсту, настройка размера, цвета и прозрачности.
* **Сравнение «До / После»** по нажатию и удержанию кнопки или клавиши.

### 3. Поддержка форматов и собственный парсер PSD
* **Поддерживаемые расширения**: `.jpg`, `.jpeg`, `.jfif`, `.png`, `.webp`, `.gif`, `.svg`, `.svgz`, `.ico`, `.cur`, `.bmp`, `.tif`, `.tiff`, `.psd`, `.avif`, `.heic`, `.heif`, `.tga`, `.exr`.
* **Нативный C++20 парсер Adobe Photoshop (`PsdParser`)**:
  * Быстрое чтение габаритов из 26-байтного заголовка `8BPS`.
  * Декодирование композитного изображения и отдельных слоёв (8 и 16 бит на канал, Raw и PackBits RLE).
  * Корректное декодирование имён слоёв из блоков Unicode `luni` (UTF-16BE) с откатом на системную ANSI-кодировку Windows.
* **Расширенные декодеры**: опциональная интеграция **OpenImageIO** (включая OpenEXR, TGA, TIFF) и **Windows Imaging Component (WIC)** в качестве резервного декодера для системных кодеков Windows (HEIC/AVIF и др.).
* **Экспорт**:
  * Сохранение в PNG, JPEG, WebP, BMP, TIFF с сохранением исходных EXIF/XMP/PNG-чанков или с полной их очисткой.
  * Встроенный **LZW-кодировщик GIF89a** с квантованием палитры (Median Cut) для сохранения отредактированных анимированных GIF с сохранением задержек кадров и цикличности.

### 4. Метаданные, AI-параметры и интеграция с Windows
* **Инспектор метаданных**:
  * Чтение EXIF-данных камеры (модель, объектив, фокусное расстояние, диафрагма, выдержка, ISO).
  * Извлечение метаданных ИИ-генерации (Stable Diffusion `parameters`, ComfyUI / PNG `tEXt` / `zTXt` / `iTXt`, XMP `dc:description`, JPEG `UserComment` / `COM`).
  * **Очистка метаданных без пересжатия**: удаление EXIF, XMP, комментариев и текстовых чанков напрямую из контейнеров PNG, JPEG и WebP.
* **Ассоциация файлов в Windows (`WindowsFileAssociation`)**:
  * Регистрация `ProgId`, `Capabilities` и `RegisteredApplications` в `HKEY_CURRENT_USER` без запроса прав администратора (UAC), уведомление Проводника (`SHChangeNotify`) и прямой переход в *Параметры Windows → Приложения по умолчанию*.
* **Интерфейс и локализация**:
  * Светлая, тёмная и системная темы оформления (автоматическое отслеживание темы Windows) с фирменным фиолетовым акцентом (`#A855F7`).
  * Двуязычный интерфейс (**Русский** / **English**) с автоматическим определением языка системы.

## Технологический стек

* **Язык**: C++20
* **Фреймворк GUI и мультимедиа**: Qt 6 (`Widgets`, `Concurrent`, `Sql`, `Svg`)
* **База данных**: SQLite (через `Qt6::Sql`)
* **Сборка и зависимости**: CMake 3.21+, Ninja, vcpkg (manifest mode)
* **Опциональные библиотеки**: OpenImageIO (`LUMINA_ENABLE_OIIO`), Windows SDK (`wincodec`, `shell32`, `ole32`)

## Сборка проекта (Windows)

### Требования
* Windows 10 / 11 (x64)
* **Visual Studio 2022** (с компонентом *Разработка классических приложений на C++*)
* **CMake** ≥ 3.21 и **Ninja**
* **vcpkg** (установленный и прописанный в переменной окружения `VCPKG_ROOT`)

### Сборка через CMake Presets

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<your-username>/LuminaPhoto.git
   cd LuminaPhoto
   ```

2. Убедитесь, что задана переменная окружения `VCPKG_ROOT` (например, `C:\vcpkg`):
   ```powershell
   $env:VCPKG_ROOT = "C:\vcpkg"
   ```

3. Сконфигурируйте и соберите Release-версию с помощью встроенного пресета `windows-x64-release`:
   ```bash
   cmake --preset windows-x64-release
   cmake --build --preset build-release
   ```

   Для отладочной сборки:
   ```bash
   cmake --preset windows-x64-debug
   cmake --build --preset build-debug
   ```

> **Примечание о зависимостях:** при первом запуске `cmake --preset ...` менеджер пакетов `vcpkg` автоматически соберёт и установит зависимости из `vcpkg.json` (`qtbase`, `qtsvg`, `qtimageformats`). Поддержка OpenImageIO по умолчанию отключена (`LUMINA_ENABLE_OIIO=OFF`) для быстрой сборки, но может быть включена флагом `-DLUMINA_ENABLE_OIIO=ON`.

## Структура проекта

```text
LuminaPhoto/
├── CMakeLists.txt                  # Конфигурация сборки CMake (C++20, Qt6, ресурсы, линковка)
├── CMakePresets.json               # Пресеты сборки Ninja + vcpkg (Debug / Release)
├── vcpkg.json                      # Манифест зависимостей vcpkg (qtbase, qtsvg, qtimageformats)
└── src/
    ├── main.cpp                    # Точка входа, выбор режима запуска (QuickViewer или MainWindow)
    ├── core/
    │   ├── AppSettings.h/.cpp      # Управление темой (System/Light/Dark), языком и палитрой Fusion
    │   ├── PhotoModels.h           # Модели данных: PhotoRecord, PhotoEdits, EffectLayer, AlbumRecord
    │   ├── LibraryDatabase.h/.cpp  # SQLite-хранилище, пакетная индексация, поиск и альбомы
    │   ├── ImageLoader.h/.cpp      # Загрузка форматов, слоевой рендеринг, EXIF/AI-метаданные, GIF89a
    │   ├── PsdParser.h/.cpp        # Нативный декодер Adobe Photoshop (.psd) со слоями и UTF-16BE
    │   └── WindowsFileAssociation.h/.cpp # Регистрация расширений в реестре HKCU без прав администратора
    └── ui/
        ├── MainWindow.h/.cpp       # Главное окно библиотеки, сетка фото, альбомы и инспектор
        ├── QuickViewerWindow.h/.cpp# Окно быстрого просмотра, кинолента, анимация, слои PSD и редактор
        ├── SettingsDialog.h        # Диалог выбора темы и языка интерфейса
        ├── FileAssociationsDialog.h# Диалог настройки ассоциаций файлов в Windows
        ├── AlbumIcons.h            # Генератор векторных иконок для пользовательских альбомов
        └── SmoothUi.h              # Кастомный рендеринг кнопок, скроллбаров и киноленты
```

## Горячие клавиши (Quick Viewer)

| Действие | Клавиша |
| :--- | :--- |
| Предыдущее / следующее фото | `←` / `→` |
| Масштаб по окну / `100%` | `F` / `0` или двойной клик |
| Увеличить / уменьшить масштаб | `+` / `-` или колесо мыши |
| Пауза / воспроизведение GIF / WebP | `Space` |
| Удалить файл в корзину | `Delete` |
| Закрыть окно просмотра | `Esc` |
