# LuminaPhoto
Быстрый нативный просмотрщик и неразрушающий редактор фотографий для Windows на C++20 и Qt 6. Поддержка 19+ форматов (включая PSD со слоями, SVG, AVIF, HEIC, WebP, EXR и анимированные GIF), слоевые эффекты, просмотр и очистка EXIF/XMP/AI-метаданных, библиотека с SQLite и интеграция с проводником Windows.
